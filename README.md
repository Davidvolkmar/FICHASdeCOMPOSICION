# Ficha de Composición · Vivienda

Presentación interactiva del ejercicio de composición (Diseño de vivienda):
7 decisiones de afuera hacia adentro con volumetrías 3D animadas, 12 principios de composición
aplicados a una vivienda urbana y el proceso de iterar hasta consolidar una forma.

## Publicar en GitHub Pages

1. Crea un repositorio **público** en GitHub (ej. `ficha-composicion`).
2. En el repositorio: **Add file → Upload files** y arrastra **todo el contenido de esta carpeta `dist`**
   (incluido el archivo oculto `.nojekyll`). `index.html` debe quedar en la raíz del repositorio.
3. **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch** → rama `main`, carpeta `/ (root)` → **Save**.
5. En 1–2 minutos queda en `https://TU-USUARIO.github.io/ficha-composicion/`. Ese es el link para compartir.

## Usar en clase

- **Navegar:** deslizar en pantalla táctil, flechas del teclado, botones ‹ › o la barra de progreso.
- **Proyectar en loop:** botón ▶ (o tecla `P`). Avanza solo y vuelve a empezar.
  Para abrir directamente en loop: `https://TU-USUARIO.github.io/ficha-composicion/#1-auto`
- **Pantalla completa:** botón ⛶ (o tecla `F`). **Índice:** botón ☰.
- **Fichas para imprimir:** botón **⤓ Fichas PDF** en la barra superior.

## Archivos

| Archivo | Uso |
|---|---|
| `index.html` | La presentación completa (HTML, estilos y scripts en un solo archivo) |
| `Ficha_Composicion_Vivienda.pdf` | Fichas 1 y 2 para imprimir |
| `favicon.svg` | Ícono de la pestaña |
| `.nojekyll` | Indica a GitHub Pages que publique los archivos tal cual |

Para actualizar: sube de nuevo el `index.html` modificado (Add file → Upload files) y haz commit.
